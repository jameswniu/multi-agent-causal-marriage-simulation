LoveWorld, a causal simulation of agent marriages. 1,000 agent couples, one year, one memory setting changed between arms. Three tiles compare control with treatment: divorced within the year 1.6% against 21.4%, trust on the last day 0.65 against 0.20, conflicts per couple-year 7.8 against 15.7. Four stages, experiment file, Rust engine, analysis, dashboard. Footer: python3 tools/figures.py --write  from results/example/summary.json.
