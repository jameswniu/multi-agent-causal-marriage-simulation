# Town art

The town is drawn with 16 pixel tiles from two packs by Kenney (www.kenney.nl), both released
under Creative Commons Zero (CC0): Tiny Town 1.1 for the ground, paths, trees and houses, and
Tiny Dungeon for the townsfolk. Their license files sit beside this note.

Only the tiles the town uses are copied here. The four roof tiles are recoloured from Tiny
Town's own roof tiles so control and treatment roofs match the dashboard's arm colours; the
bottom pixel row of each keeps the original brown eave so every roof sits on the same wall.
